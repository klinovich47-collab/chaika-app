# ЧАЙКА

Telegram Mini App / web-карта событий Санкт-Петербурга.

## Production

- Frontend: Vercel, `https://chaika-app.vercel.app/`
- Telegram bot: `@chaika47bot`
- Backend/database: Supabase
- Static production build: `npm run build` → `dist/`

## Что уже работает

- карта и лента событий;
- ручной выбор точки на карте и создание события долгим нажатием;
- группировка событий в одной координате, premium первыми;
- verified Telegram auth;
- упрощённое создание пользовательского события: название, значок, время, длительность до 24 часов, описание, точка и ссылка;
- пользовательские события без фото, цены, возраста, координат в интерфейсе и premium-настроек;
- создание и удаление собственных событий;
- «Мои события»;
- отдельная роль модератора для проверки, публикации, отклонения и удаления событий;
- администраторские настройки Telegram-форума изолированы от модераторских прав;
- серверная проверка названия, описания и ссылки со сленгом/обфускацией;
- deep links на конкретное событие через `@chaika47bot`;
- публичные источники обновляются каждые 30 минут, открытое приложение — каждые 5 минут;
- события без указанного окончания удаляются через час после начала, а события с `expires_at` — сразу после окончания;
- KudaGo: общий поток + отдельные проходы по concert / party / festival;
- Union Bar: расписание с официального сайта;
- VNVNC: публичная афиша/Telegram как источник, когда появляются актуальные даты;
- синхронизация внешних музыкальных событий и их фотографий во вкладку «Концерты».

## Supabase

Актуальные Edge Functions лежат в `supabase/functions/`.
Последние изменения схемы — в `supabase/migrations/`.

Секреты **не хранить в GitHub**. В Supabase Secrets используются:

- `TELEGRAM_BOT_TOKEN` — обязателен;
- `OPENAI_API_KEY` — включает автоматическую `omni-moderation-latest` проверку текста;
- `TIMEPAD_TOKEN` — опциональный дополнительный источник.
